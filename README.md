# ClearBurn Environmental Solutions Website

This repository contains a static website for ClearBurn Environmental Solutions, built to present the company as a serious environmental land management and fire mitigation firm serving Texas.

## Files

- `index.html` — Homepage with hero, services preview, industries, service area, and lead generation CTA.
- `services.html` — Detailed service descriptions and quote CTAs for each offering.
- `projects.html` — Project placeholder page for case study content.
- `industries.html` — Industry-specific messaging for developers, municipalities, utilities, and more.
- `about.html` — Leadership, mission, and service area.
- `contact.html` — Quote request form and contact details.
- `styles.css` — Brand-aligned layout and responsive styling.
- `script.js` — Mobile menu toggle and quote form confirmation behavior.

## Notes

- The site uses the brand palette: forest green, secondary green, orange, charcoal, light gray, and white.
- The design is intentionally direct, professional, and capable.
- `contact.html` includes a non-functional static form placeholder with confirmation messaging.
